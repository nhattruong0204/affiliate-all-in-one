# API Specification

Status: PROPOSED. Machine-readable draft: `docs/api/openapi.yaml` (OpenAPI 3.1). Once `web` exists, the spec is generated by `utoipa` and CI fails on undeclared drift.

## 1. Surfaces
| Prefix | Consumers | Auth |
|---|---|---|
| `/` (HTML) | Browsers (Leptos SSR) | Session cookie |
| `/api/v1/*` | Our UI (islands), future mobile apps | Session cookie + CSRF header. Bearer tokens are post-V1 |
| `/admin/api/v1/*` | Admin console | Staff session + TOTP + role |
| `/go/{token}` | Anyone with the link | none |
| `/hooks/{provider}` | Providers | Provider-specific verification |
| `/healthz`, `/readyz` | Caddy, monitors | none (no data) |
| `/metrics` | Prometheus (internal network only) | network ACL |

## 2. Conventions
- JSON, `snake_case`. Money is `{ "amount": 35000, "currency": "VND" }` (integer). Timestamps are RFC 3339 UTC.
- IDs are UUIDv7 strings. Public URLs never expose sequential IDs.
- **Pagination:** keyset. `?limit=20&cursor=<opaque>`. Response `{ "data": [...], "next_cursor": "..." | null }`. `limit` ≤ 100.
- **Filtering:** explicit whitelisted query params (`status`, `from`, `to`, `merchant`). Sort is fixed per endpoint unless documented.
- **Idempotency:** `Idempotency-Key` header (UUID) is **required** on POSTs that create money-relevant resources (`/withdrawals`, `/bank-accounts`, admin money actions). The key is stored 24h, scoped per user and route. A replay with the same body returns the stored response. A different body → `409 idempotency_key_reused`.
- **Concurrency:** admin config updates send `If-Match: <version>` → `412` on mismatch.
- **Errors** (RFC 9457 problem+json):
```json
{ "type": "https://docs.aaio.vn/errors/insufficient_balance", "title": "Insufficient available balance",
  "status": 422, "code": "insufficient_balance", "detail": "Số dư khả dụng không đủ.",
  "trace_id": "4bf92f3577b34da6a3ce929d0e0e4736", "errors": [{"field": "amount", "code": "min"}] }
```
`code` is stable and machine-readable. `detail` is localized per `Accept-Language` / user locale.
- **Rate limits:** `429` with `Retry-After`. Default buckets: anonymous analyze 10/min/IP, link create 30/hour/user, login 5/15min/account plus 20/15min/IP, withdrawals 5/day/user.
- **Versioning:** URI major version. Additive changes are allowed within v1. Removal or semantic change → v2, with v1 supported ≥ 6 months after v2 GA. `Deprecation` and `Sunset` headers.

## 3. Endpoint catalogue (V1)

### Public / auth
| Method | Path | Purpose |
|---|---|---|
| POST | `/api/v1/analyze` | Parse input, detect merchant, preview + estimate (no link). Anonymous allowed |
| POST | `/api/v1/auth/register` | Email/password sign-up (+ consent versions) |
| POST | `/api/v1/auth/login` | Login → session cookie |
| POST | `/api/v1/auth/logout` | Revoke current session |
| GET | `/auth/google/start`, `/auth/google/callback` | OIDC (browser redirects) |
| POST | `/api/v1/auth/verify-email` | Consume token |
| POST | `/api/v1/auth/password/forgot`, `/password/reset` | Recovery (constant response) |
| POST | `/api/v1/auth/step-up` | Re-auth for sensitive actions |

### User
| Method | Path | Purpose |
|---|---|---|
| POST | `/api/v1/links` | Create tracked link (requires login) |
| GET | `/api/v1/links` | My link history |
| GET | `/api/v1/me` / PATCH | Profile, locale, theme |
| GET | `/api/v1/wallet` | Balances by state (from ledger) |
| GET | `/api/v1/wallet/transactions` | Statement (ledger entries on my accounts, humanized) |
| GET | `/api/v1/orders` | Conversions/entitlements list |
| GET | `/api/v1/orders/{id}` | Detail + timeline |
| GET/POST/DELETE | `/api/v1/bank-accounts` | Manage payout destination (step-up) |
| GET/POST | `/api/v1/withdrawals` | List / request (step-up + Idempotency-Key) |
| POST | `/api/v1/withdrawals/{id}/cancel` | Cancel before review |
| GET/POST | `/api/v1/tickets` | Support + missing cashback claims |
| GET | `/api/v1/notifications`, POST `/read` | Notification centre |
| GET | `/api/v1/referrals` | (V1.x) referral stats |
| POST | `/api/v1/checkins` | (V1.x) daily check-in, idempotent per VN day |
| POST | `/api/v1/me/data-export`, `/me/close` | Data-subject rights |

### Admin (roles in `ADMIN_DASHBOARD.md` §2)
`/admin/api/v1/users`, `/providers`, `/merchants`, `/campaigns`, `/routes`, `/rules` (+ `/rules/{id}/versions`, approval), `/conversions`, `/reconciliation-cases`, `/settlements` (+ allocate), `/ledger/accounts`, `/ledger/transactions`, `/adjustments` (maker-checker), `/withdrawals` (+ review/approve/submit/mark-paid/fail/reconcile), `/bank-statements/import`, `/tickets`, `/flags`, `/config`, `/jobs` (+ requeue), `/audit-log`, `/content/posts`, `/legal-documents`, `/reports/*`, `/exports/*` (async CSV).

### Hooks
`POST|GET /hooks/accesstrade`: disabled until the VN postback is confirmed (OB-5). It accepts, logs redacted, and enqueues a fetch-by-id job. It always responds 200 quickly once the event is persisted, so the provider doesn't retry storms.

## 4. Authentication requirements summary
| Action | Requirement |
|---|---|
| Analyze | none (rate-limited, CAPTCHA after threshold, Cloudflare Turnstile or similar, PROPOSED) |
| Create link, view wallet/orders | user session |
| Add/change bank account, withdraw, change email/password | session + step-up ≤ 5 min |
| Any admin read | staff session + TOTP |
| Admin money action | staff session + TOTP + role + step-up + (maker-checker where listed) |
